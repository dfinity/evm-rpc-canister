## Motivation

Upgrade the EVM RPC canister to the latest version [v2.9.0](https://github.com/dfinity/evm-rpc-canister/releases/tag/evm_rpc-v2.9.0).

This release fixes failing `eth_getTransactionReceipt` requests. Some JSON-RPC providers, such as PublicNode and BlockPi, serve the same transaction receipt with the JSON fields in a different order depending on which backend handles the request. The currently deployed version does not normalize receipt responses before HTTPS outcall consensus, so replicas receiving different field orders fail to reach consensus, and the request fails for that provider. This currently causes transaction receipt lookups by the ckETH minter to fail. Version v2.9.0 normalizes the responses of `eth_getTransactionReceipt`, `eth_call` and `eth_getTransactionCount` before consensus.

The release also bumps `ic-cdk` to v0.20.2 and Rust to v1.97.1, and upgrades other dependencies.

See the GitHub release [v2.9.0](https://github.com/dfinity/evm-rpc-canister/releases/tag/evm_rpc-v2.9.0) for more details.
